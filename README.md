# CS50x — Introduction to Computer Science
My repository for projects completed while taking **CS50x**, Harvard’s free online introduction to computer science. The course explores problem-solving and programming with Scratch, C, Python, SQL, and web technologies.
This README summarizes the weekly projects and suggests filenames for saving them. Assignment choices can vary, so I’ll use the filenames and requirements that match my course version.

## Course Topics
- Week 0: Scratch- Week 1: C- Week 2: Arrays- Week 3: Algorithms- Week 4: Memory- Week 5: Data Structures- Week 6: Python- Week 7: SQL- Week 8: HTML, CSS, JavaScript- Week 9: Flask- Final project

## Projects

### Week 0 — Scratch
Create an interactive project using Scratch. Practice events, loops, conditionals, variables, and custom blocks.
scratch-project.sb3

### Week 1 — C
Write introductory programs in C, practicing input and output, variables, functions, conditionals, and loops.
hello.c — Print a greeting
mario.c — Print a Mario-style pyramid
cash.c — Calculate the minimum coins needed to give change
credit.c — Check whether a credit-card number is valid

### Week 2 — Arrays
Work with strings and arrays in C, including text analysis and encryption.
readability.c — Estimate the reading level of a text
scrabble.c — Compare the Scrabble scores of two words
substitution.c — Encrypt text using a substitution cipher

### Week 3 — Algorithms
Study algorithmic efficiency and implement searching, sorting, or election-related programs.
plurality.c — Simulate a plurality election
runoff.c — Simulate a ranked-choice runoff election
tideman.c — Implement the Tideman ranked-pairs election system
sort.c — Identify the sorting algorithm used by provided code

### Week 4 — Memory
Explore pointers, memory, and file handling through image-processing and data-recovery exercises.
filter.c — Apply filters to bitmap images
recover.c — Recover JPEG images from a memory-card file

### Week 5 — Data Structures
Use data structures to organize and search information in a spell-checking program.
speller.c — Run a spell-checker against a text file
dictionary.c — Implement the dictionary functions used by the spell-checker

### Week 6 — Python
Practice Python by solving programming problems involving functions, libraries, and data handling.
hello.py — Print a greeting
mario.py — Print a Mario-style pyramid
cash.py — Calculate the minimum coins needed to give change
credit.py — Check whether a credit-card number is valid
readability.py — Estimate the reading level of a text
dna.py — Identify a person by comparing DNA data

### Week 7 — SQL
Use SQL queries to explore databases and answer questions about their data.
songs.sql — Query a music database
movies.sql — Query a movie database
fiftyville.sql — Investigate a mystery by querying a database.

### Week 8 — HTML, CSS, and JavaScript
Build a website and use HTML, CSS, and JavaScript to create its structure, styling, and interactive features.
index.html — Main webpage
styles.css — Website styles
script.js — Interactive behavior, if needed
### Week 9 — Flask
Build a web application using Flask and Python, with templates, forms, and database features.
app.py — Main Flask application
helpers.py — Supporting functions, if needed
requirements.txt — Python dependencies
templates/ — HTML templates
static/ — CSS, images, and other static files.

### Final Project
Plan and build an original program, website, or application that applies skills learned in the course. Choose a descriptive name that reflects what the project does.
README.md
main.py
